# GymClub - Gestion de Club de Sport & Fitness

Plateforme web de gestion et de réservation pour club de sport / fitness développée avec React et Node.js.

## Fonctionnalités
- Tableau de bord des membres et abonnements
- Gestion des cours et planning d'entraînement
- Interface interactive et réactive

## Installation et Démarrage
```bash
# Installation des dépendances
npm install

# Lancement en mode développement
npm start
```

## Technologies
- React.js
- Node.js / Express
- CSS3 / HTML5
